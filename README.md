Neon Vice turns any photo and caption into GTA 6-style cover art: diagonal multi-panel posters, bold poster lettering and a neon-night Vice City grade (plus sunset and Vice pink), exported as a PNG in 1080×1080, 1080×1350 and 1920×1080. It runs offline in a desktop browser from its own static files; photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
